# FRONTEND FOR XQUARE INFRASTRUCTURE V3

---

## 기술 스택

| 구분                                | 사용 기술  |
| ----------------------------------- | ---------- |
| **언어 (Language)**                 | TypeScript |
| **프레임워크 (Framework)**          | React 18   |
| **빌드 도구 (Build Tool)**          | Vite       |
| **스타일링 (Styling)**              | Emotion    |
| **패키지 관리자 (Package Manager)** | Bun        |
| **모노레포 / 빌드 시스템**          | Turborepo  |

---

## 명령어

### 시작하기(의존성 설치)

```
bun install
```

### 개발 서버 실행하기

```
bun run dev --filter=@xquare/admin-application
```

```
bun run dev --filter=@xquare/user-application
```
